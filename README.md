# Hssab

Partage de dépenses entre colocataires et amis : qui doit combien à qui.

## Lancer le projet

    cp .env.example .env
    docker compose up --build

- Application : http://localhost:5173
- API : http://localhost:8000/api/health/

## Stack
Django, PostgreSQL, React, Vite, TypeScript, Tailwind, Docker, GitHub Actions
